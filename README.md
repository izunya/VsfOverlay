# VsfOverlay

VSeeFace 아바타를 **데스크톱 위에 투명하게** 띄워주는 프로그램입니다.

배경 없이 캐릭터만 화면에 남고, 원하는 모니터의 원하는 자리에 둘 수 있습니다.
평소엔 마우스가 캐릭터를 그냥 통과하므로 작업에 방해되지 않습니다.

---

## 다운로드

1. **[최신 버전 받기](../../releases/latest)** → `VsfOverlay.exe`
2. 아무 폴더에나 두고 더블클릭

설치 과정 없습니다. .NET 같은 것도 따로 안 깔아도 됩니다.
Windows 10 / 11 (64비트) · DirectX 11 지원 그래픽카드.

---

## 처음 한 번만 하면 되는 설정

VSeeFace 쪽에서 화면을 내보내도록 켜줘야 합니다.

1. **[Visual C++ 2010 재배포 패키지 (x64)](https://www.microsoft.com/download/details.aspx?id=26999)** 설치
   → 이게 없으면 아래 2번 항목이 회색으로 비활성화됩니다
2. VSeeFace 에서 `Settings` → `General settings` → **`Spout2 image capture support` 체크**
3. VSeeFace 창 **오른쪽 아래의 작은 `※` 버튼**을 클릭해서 UI 숨기기
   → 안 숨기면 버튼들이 같이 딸려 나옵니다 (`Space` 키로도 토글됩니다)
4. `VsfOverlay.exe` 실행

아바타가 화면에 뜨면 끝입니다.

## 사용법

작업 표시줄 오른쪽 아래 **트레이 아이콘**을 더블클릭하면 설정 창이 열립니다.

### 단축키

| 키 | 기능 |
|---|---|
| `Ctrl` + `Alt` + `O` | **조작 모드** 켜기 / 끄기 |
| `Ctrl` + `Alt` + `K` | **자동 크롭** — 캐릭터 주변 빈 여백을 잘라냄 |
| `Ctrl` + `Alt` + `P` | 숨기기 / 보이기 |
| `Ctrl` + `Alt` + `I` | 설정 창 열기 |

### 위치와 크기 바꾸기

1. `Ctrl` + `Alt` + `O` 를 눌러 **조작 모드**로 들어갑니다
2. 캐릭터를 **드래그**해서 옮기고, **마우스 휠**로 크기를 조절합니다
   (`Ctrl` + 휠 = 미세 조절 / 우클릭 = 메뉴)
3. 다 됐으면 `Ctrl` + `Alt` + `O` 를 다시 눌러 돌아옵니다

위치와 크기는 자동 저장되고, 껐다 켜도 그 자리에 다시 뜹니다.

### 캐릭터 주변이 휑할 때

`Ctrl` + `Alt` + `K` 를 누르면 캐릭터에 딱 맞게 잘라줍니다.
팔을 벌린 자세처럼 **가장 크게 보이는 순간**에 누르는 게 좋습니다.

### 그 외 설정 창에서 할 수 있는 것

- 여러 모니터 중 어디에 띄울지 선택
- 투명도 조절
- 마우스를 올리면 캐릭터가 흐려지게 (가려진 걸 볼 때 편합니다)
- 항상 맨 위에 표시 끄기

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 아바타가 안 보임 | VSeeFace 에서 `Spout2 image capture support` 가 켜져 있는지 확인 |
| 그 항목이 회색으로 비활성화 | Visual C++ 2010 재배포 패키지 (x64) 설치 |
| 아바타에 VSeeFace UI 가 같이 나옴 | VSeeFace 오른쪽 아래 `※` 버튼으로 UI 숨기기 |
| 여전히 안 보임 | 그래픽카드가 여러 개인 PC라면, Windows `설정 → 시스템 → 디스플레이 → 그래픽`에서 **VSeeFace 와 VsfOverlay 를 둘 다 같은 그래픽카드(고성능)** 로 지정 |
| 게임 위에 안 올라옴 | 게임을 **전체화면** 대신 **테두리 없는 창 모드**로 실행 |
| 단축키가 안 먹음 | 다른 프로그램이 같은 조합을 쓰는 중입니다. 트레이 아이콘 메뉴로 조작하세요 |
| 프레임이 뚝뚝 끊김 | VSeeFace 를 관리자 권한으로 실행 |

그래도 안 되면 `VsfOverlay.exe --diag` 를 실행해 보세요.
진단 결과가 `%TEMP%\vsf-overlay-diag.txt` 에 저장됩니다.
